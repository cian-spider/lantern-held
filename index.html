How it was made

There is no DAW, no sample library and no plugin in this recording. Every sound is additive synthesis written for this piece: an inharmonic piano model, a bowed cello with a 380 Hz body resonance, and a four-voice detuned string ensemble. The reverb is a generated impulse response. The composition lives in score.py, the instruments in render.py, and the result is reproducible: a rebuild from source is byte-identical to the file above.

All material original. No samples, loops, presets or quoted recordings. Written and rendered by Cian.
